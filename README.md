- **선수 등록:** 등록 선수가 128명으로 가득 차 있어도 나의 페넌트에서 강화한 선수를 기존 예약 칸에 정상 갱신하도록 수정했습니다.
- **특수능력 구매:** ◎ 능력을 구입했을 때 대응하는 ○ 능력이 남던 누락 처리를 보완했습니다. 이미 저장된 중복 능력을 일괄 정리하는 기능은 아닙니다.
- **오리지널 변화구 잔상:** 다른 팀의 기본 투수를 불러올 때 이전 선수의 오리지널 변화구 이름·값이 남던 초기화 누락을 수정했습니다.
- **오리지널 변화구 강화 이벤트:** 해당 변화구를 잃은 뒤에도 강화 이벤트가 진행돼 포인트와 체력이 소모되던 문제를 수정했습니다.
- **카드 야구 스리번트:** 2스트라이크에서 번트 파울로 아웃돼도 같은 타자가 남던 문제를 수정했습니다.
- **장내 아나운스·실황 일부:** 스가·후유노·킨조/카네시로·후지사와의 음성 번호와 오릭스 히다카/키타가와의 뒤바뀐 실황 연결을 수정했습니다. 원본에 올바른 녹음이 없는 세가타·핫토리 등은 유지했습니다.
- **변화구 그래프:** 우투수 슬라이더 방향 또는 좌투수 슈트 방향에 구종이 두 개 있을 때 첫 구종의 변화량이 한 단계 높게 보이던 화살표 선택을 수정했습니다.
- **페넌트 관전:** 경기 중 옵션을 통해 타격·투구·수비·주루·감독 조작을 수동으로 바꾸던 문제를 막았습니다. 옵션 화면의 선택은 움직일 수 있지만 확인 시 관전 조작 설정은 유지됩니다.
- **동료 구속 보너스:** 히키타를 포함해 기본 구속이 145km/h 이상인 동료 투수에게 평가 보너스가 붙지 않던 제한을 없앴습니다. 증가 상한은 165km/h입니다.
